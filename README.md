# Fret Werk

Fret Werk is a web application for designing and visualizing guitar fretboards. It allows users to customize various aspects of the fretboard, including the number of frets, scale length, and tuning. The application provides an interactive interface for users to explore different chord shapes, scales, and fingerings.

This project was heavily inspired by [FretFind2D](https://www.ekips.org/tools/guitar/fretfind2d/). This is an updated version of that project, rewritten in Vue 3 and TypeScript, with a more modern and responsive design.

## Getting Started

Fret Werk is built using Vue 3 and TypeScript. It uses Vite as the build tool, and Pmpm for package management. To get started with the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/fretwerk/fretwerk.git
   ```
2. Navigate to the project directory:
   ```bash
   cd fretwerk
   ```
3. Install the dependencies:
   ```bash
   pnpm install
   ```
4. Start the development server:
   ```bash
   pnpm run dev
   ```
5. Open your web browser and go to `http://localhost:5173` to view the application.
6. Build the project for production:
   ```bash
   pnpm run build
   ```
