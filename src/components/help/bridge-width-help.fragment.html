The bridge width is the distance along the bridge from the center of the first string to the center of the last string. This will affect how far apart the strings are spaced from one another.

This distance must be measured on the actual bridge, as string spacing on most bridges cannot be adjusted. Most electric guitar and bass bridges use a common spacing. If unsure of the spacing, measure distance between the outer saddle slots or refer to the manufacturer's specifications.

String spacing for bridges is typically specified as the distance between the centers of each string, which are equally spaced. To determine this distance, multiply the string spacing by the number of spaces between strings, which will be 1 less than the number of string. For example, 5 spaces for a 6 string guitar, or 3 spaces for a 4 string bass).

The larger the delta between the nut width and the bridge width, the steeper the angle of the strings as they approach the bridge. This will mean the the distance between strings at higher frets will be much farther apart than at the nut, affecting the feel of the guitar neck.
