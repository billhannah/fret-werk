Scale length is distance an open string can vibrate,measured from the front edge of the nut (where the string leaves the nut toward the fretboard) to the point where the string breaks over the bridge saddle (typically doubled as the distance from the nut to the center of the 12th fret).

A good way to think about it is that scale length sets the physical boundary conditions for a vibrating string: length, tension, and mass per unit length (gauge) are locked together with pitch. Change the scale length and you change how tight a string must be pulled to hit a target pitch, how much physical stretch is required to bend a note by a semitone, and where every fret sits along the neck.

Scale length is a fundamental property of a stringed instrument. If replacing the neck of and existing guitar, the scale length for the new neck must match the original scale length, or the bridge must be moved to match the new scale length. If this is not done, the guitar will not intonate properly and will sound out of tune when fretting notes.
